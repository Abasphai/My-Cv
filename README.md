# Mohamud Mohamed Abas · Portfolio

[Open the live portfolio](https://mohamud-abas-portfolio-98dbff.fabled-seal-1361.chatgpt.site/)

Open web/index.html in your browser to preview the design. Edit the content in web/index.html and the styles in web/style.css. All five images are in web/images.

The frontend uses HTML and CSS. The inquiry form needs the hosted Worker and its D1 database. Opening the HTML file locally displays the form.

The hosted form stores inquiries in D1. The /inbox page displays the latest 100 entries when accessed through ChatGPT using abasphai2053@gmail.com. The email and telephone links provide direct contact.

To build the Worker with Node.js, run npm run build. The build writes dist/server/index.js. Bind D1 as DB and apply drizzle/0000_inquiries.sql when deploying to a new database.
